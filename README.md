# Ali Halal Restaurant Digital Menu System

A full-stack digital menu and order management system built with MERN stack.

## Getting Started

### Prerequisites

- Node.js
- MongoDB

### Installation

1.  Clone the repository.
2.  Navigate to the `server` directory and install dependencies:
    ```bash
    cd server
    npm install
    ```
3.  Navigate to the `client` directory and install dependencies:
    ```bash
    cd client
    npm install
    ```

### Usage

1.  Start the backend server:
    ```bash
    cd server
    npm run dev
    ```
2.  Start the frontend application:
    ```bash
    cd client
    npm start
    ```

### Features

-   **Customer**: Scan QR code, browse menu, place order, view status.
-   **Admin**: Real-time order dashboard, manage order status.

### Tech Stack

-   **Frontend**: React.js
-   **Backend**: Node.js, Express.js
-   **Database**: MongoDB
-   **Real-time**: Socket.io
